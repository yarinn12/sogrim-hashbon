# Local app fonts

These are the same Google Fonts WOFF2 subsets served to the app on 2026-10-10
for `Inter:wght@500;600;700;800;900` and `Rubik:wght@400;500;600;700;800;900`.
The files are served locally so Hebrew and numeric text retain their intended
faces when Google Fonts is unavailable. `SOURCES.json` records every source URL
and SHA-256 hash. `local.css` keeps the source stylesheet's Unicode ranges and
uses each variable file for its supported weight range.

Rubik and Inter are licensed under the SIL Open Font License 1.1. Their license
texts are included in `OFL-Rubik.txt` and `OFL-Inter.txt`. Source metadata:

- https://github.com/google/fonts/tree/main/ofl/rubik
- https://github.com/google/fonts/tree/main/ofl/inter
