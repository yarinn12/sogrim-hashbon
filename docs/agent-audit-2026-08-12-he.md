# סבב סוכנים - 12 באוגוסט 2026

## תמונת מצב

חמישה סוכנים בדקו במקביל את האפליקציה כמוצר מובייל. הממצאים כאן מאומתים באמצעות קוד, בדיקות קיימות או שחזור באמולטור. מסך הבית, שפת המותג וה-glow המאושרים נשמרים.

## חסמים חיצוניים

- **P0 - סביבת הייצור מחזירה HTTP 402.** הזמנות, QR, התראות שרת, דפי פרטיות ומחיקת חשבון וקישורי App/Universal Links תלויים כרגע ב-`sogrim-hashbon.vercel.app` ולכן אינם מוכנים לשחרור עד שהאירוח חוזר ל-200 או מועבר בצורה אטומית לכתובת אחרת.
- **iOS - אין עדיין build חתום ומאומת.** ההכנות המקומיות קיימות, אך נדרשים חשבון Apple פעיל, Team ID, קובץ association חי וארכיון Xcode/TestFlight.

## תיקונים בביצוע

1. חסימת שמירה ישנה לאחר מעבר בין חשבונות ושמירת snapshot בלתי משתנה.
2. הרשאות ניהול להסרת משתתפים ואיחוד זהויות.
3. timeout לבקשות חברים והתראות כדי שחזרה לאפליקציה לא תיתקע לצמיתות.
4. מסך משתתפים מלא, תיקון חפיפה בשיתוף ומרווח תחתון בטקסט מוגדל.
5. חסימת השתלטות על workspace משותף דרך metadata בהרשמה ותיקון race בבקשות חברות הדדיות.

## סבב הבא

- רינדור מדורג לאירועים גדולים; ב-1,000 הוצאות נמדדה חסימה של יותר מ-10 שניות ומאות אלפי רכיבי DOM.
- תיקון בדיקת זמן העלייה ומדידה בגרסת Release על מכשיר Android בינוני.
- השלמת cache אופליין אוטומטי מתוך גרף ה-imports.
- בדיקת עומס אמיתית של 50/100/250 עורכים מול סביבת staging.
- בדיקת הרשאות שרת לכל שינוי באירוע משותף, מעבר לידיעת מפתח השיתוף בלבד.
