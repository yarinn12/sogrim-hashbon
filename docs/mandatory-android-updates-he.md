# עדכוני Android

מנגנון החסימה הישן הורחב למדיניות עדכונים רגילים וקריטיים עבור Android ו־iOS. ההוראות המעודכנות נמצאות ב־[מדיניות העדכונים](native-update-policy-20261011.md).

`ANDROID_MIN_SUPPORTED_BUILD=0` נשאר ערך ברירת המחדל. סף גבוה מאפס לבדו אינו מפעיל חסימה: נדרשים גם build חדש שזמינותו אומתה, סימון זמינות מלאה וסימון מפורש שהעדכון קריטי. אין להפעיל את הסף עד להחלטת שחרור נפרדת.
