# עדכון חובה ב-Android

האפליקציה כוללת החל מגרסה `3.53` (build `76`) מנגנון עדכון חובה. המנגנון נשלט דרך משתנה הסביבה:

```text
ANDROID_MIN_SUPPORTED_BUILD=0
```

הערך `0` משאיר את החסימה כבויה. אין להעלות אותו לפני שהגרסה החדשה זמינה בפועל ב-Google Play לכל קהל היעד.

## הפעלה בטוחה

1. מעלים ל-Google Play גרסה חדשה שמכילה את מנגנון העדכון.
2. ממתינים עד שהגרסה זמינה להתקנה במסלול הרצוי.
3. בודקים ממכשיר אמיתי שניתן לעדכן אליה.
4. רק אז מגדירים בשרת את `ANDROID_MIN_SUPPORTED_BUILD` למספר ה-build החדש.
5. בודקים בגרסה ישנה שמופיע מסך העדכון ושכפתור "עדכון עכשיו" פותח את דף האפליקציה ב-Google Play.

לביטול מיידי של החסימה מחזירים את הערך ל-`0` ומפרסמים מחדש את הגדרות השרת.

## מגבלת הגרסה הראשונה

אי אפשר לחסום מרחוק גרסה שכבר הותקנה אם היא יצאה לפני שמנגנון העדכון נכלל בה. לכן build `76` הוא בסיס המנגנון; ניתן יהיה לאכוף באמצעותו עדכונים ל-build `77` ומעלה.
