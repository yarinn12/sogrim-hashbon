# סוגרים חשבון 3.42 (65)

- נוספה בדיקת יציבות אנונימית לפי גרסת אפליקציה, ללא שמות, סכומים או תוכן אירועים.
- שופרה התאוששות מתקלות זמניות בטעינה, שמירה, חברים, התראות וקישורי הזמנה.
- חוזקו פרטיות המשתמשים, דיווח וחסימה בלי לפגוע בהיסטוריה הכספית.
- בוצעו תיקוני יציבות וסנכרון עבור כמה משתתפים שמעדכנים אירוע במקביל.
