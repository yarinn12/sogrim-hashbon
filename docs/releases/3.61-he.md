# סוגרים חשבון 3.61 (86)

## מה השתנה

- צומצם ריצוד במסכי הוספת הוצאה ובמעברים בין שלבים.
- כל שלב בהוספת הוצאה נפתח מראש המסך גם אחרי גלילה בשלב הקודם.
- תוקנו חפיפות של כפתורי ניווט ומתגי ניהול בכתב מוגדל.
- הורחבו בדיקות המובייל כדי לזהות רכיבים שמסתירים כפתורים או מונעים לחיצה.
- מנגנון החלוקה הישירה עודכן כך שהחלפת מצב התחשבנות מחושבת ונשמרת באופן עקבי.

## אימות לפני הפצה

- קוד הממשק ב-AAB זהה לקוד שנפרס ב-`sogrim-hesbon-app.vercel.app`.
- סביבת Android פונה רק לכתובת Vercel החדשה ולפרויקט Supabase הפעיל.
- בדיקות יחידה, מסכי מובייל, כתב מוגדל ומסע Android מלא עברו ללא כשל.
