# PWA 465 — חיזוק בעלות על שמירה וסנכרון

- תשובות מאוחרות משמירה, טעינה וסנכרון רקע אינן יכולות לעדכן את האחסון המקומי או את חיווי הסנכרון של חשבון אחר.
- רענון התחברות קשור לחשבון ולמחזור החיים שבהם התחילה הבקשה. יציאה וחזרה לאותו חשבון אינן מחיות בקשה ישנה; רענון סביבת עבודה באותו מחזור חיים נשאר נתמך.
- שחזור רשימת האירועים מפסיק במעבר חשבון, לפני שתוכן ישן יכול להישלח לאינדקס האישי של החשבון החדש.
- שמירה ישנה שממתינה להגדרות החיבור אינה דורסת שינוי חדש יותר בתור המקומי, גם ברגע ביניים שבו הדפדפן עלול להיסגר.
- כשל אמיתי נשאר גלוי ומסווג; אין שינוי הרשאות, הסתרת כשלים או אישור סנכרון מדומה.

אימות: 2,117 בדיקות קוד עברו, כולל 11 תרחישי התנהגות חדשים, וכן 10 תרחישי דפדפן. בדיקות הדפדפן משתמשות במידע ובשרתים מדומים; הן אינן בדיקת שני מכשירים פיזיים מול נתוני משתמשים.

קלוד בדפדפן Chrome שחזר באופן עצמאי את התקלה של כתיבת תשובה מאוחרת לאחסון החשבון האחר. מגבלת השימוש שלו עצרה את הבדיקה לפני ביקורת התיקון; תיקוני הקוד ובדיקתם הסופית בוצעו ב-Codex. לא נרכש שימוש נוסף.
