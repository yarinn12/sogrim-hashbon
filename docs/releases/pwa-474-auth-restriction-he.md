# PWA 474 — שמירת חשבון בזמן הגבלת שירות

## מה תוקן

- תשובת HTTP 402 משירות החשבון מסווגת כעת כחסם שירות זמני ולא כאישור לכך שה-session של המשתמש אינו תקין.
- session קיים נשמר במכשיר כדי לאפשר התאוששות כשהשירות חוזר, במקום למחוק אישורים תקינים ולדרוש כניסה חוזרת.
- ניסיון כניסה חדש שמקבל 402 מציג הודעה מדויקת שהשירות אינו זמין כרגע, בלי להאשים חיבור אינטרנט או חשבון Google.

## גבולות התיקון

התיקון אינו מסיר הגבלת מכסה פעילה אצל Supabase ואינו גורם להתחברות חדשה להצליח בזמן שהשירות מחזיר 402. הוא מגן על מצב החשבון המקומי ומונע החמרה מיותרת עד שהשירות משוחרר.

## אימות

- בדיקות Auth ממוקדות מכסות תשובת 402 אמיתית מ-endpoint החלפת ID token.
- 401 ו-403 נשארים כשלים סופיים שמבטלים session לא תקין.
- חבילת הקוד המלאה עברה לפני הכנת גרסת ה-PWA.
