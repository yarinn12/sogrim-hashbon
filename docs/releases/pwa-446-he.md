# PWA 446

- מחליף את קנבס הטלפון ברוחב 430px בפריסת iPad רספונסיבית עד 960px, לאורך ולרוחב.
- מרחיב את סרגל הניווט וחלונות האירוע וההוצאה בטאבלט תוך שמירה על אזורי ה־safe area.
- מעביר את כפתור „אירוע חדש” לזרימת המסמך עם מרווח קבוע, ללא חפיפה או ריחוף מעל הכותרת.
- שומר על פריסת iPhone מלאה ללא גלילה אופקית ובמטרות מגע של 44px לפחות.
- מוסיף בדיקות WebKit ייעודיות לדף הבית, אירועים, התראות, פרופיל, יצירת אירוע והזנת הוצאה ב־iPad וב־iPhone.
