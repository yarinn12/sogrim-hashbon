# PWA 452

## מה תוקן

- תוקנה בפועל הצטרפות ישנה שנפדתה לפני PWA 451 ונשארה כחברות זמנית בלי משתתף קנוני ובלי אינדקס בחשבון האישי.
- נוסף כלי שחזור מבוקר שמזהה רק מימושי קישור פתוח שפגו במצב הביניים הזה.
- כלי השחזור מוסיף את פרופיל החשבון לאירוע, מאנדקס את האירוע בחשבון האישי ומאפס את מצב הביניים בטרנזקציה אחת.
- מעטפת PWA 452 מאלצת התקנות ולשוניות ישנות להוריד את גרסת ההצטרפות המתוקנת.

## בטיחות ואימות

- ברירת המחדל היא הדמיה בלבד; כתיבה מתבצעת רק עם `--apply`.
- לפני כתיבה נוצר גיבוי מקומי, השורות ננעלות ומצב ה־JSON מושווה כדי לזהות שינוי מקביל.
- התיקון מסרב לשנות הוצאות או העברות ומריץ את אימות התקינות הכספית לפני הכתיבה.
- לאחר התיקון אומתו חברות פעילה, משתתף קנוני ואירוע מאונדקס בחשבון האישי.
