# PWA 451

## מה תוקן

- הצטרפות של חשבון חדש דרך קישור פתוח אינה מנסה עוד לאנדקס את האירוע לפני שהחשבון נוסף לרשימת המשתתפים הקנונית.
- לאחר אימות הקישור, הלקוח מקבל את פרטי האירוע, מוסיף את המשתתף ושומר תחילה את האירוע המשותף; רק אחר כך נשמר האינדקס בחשבון האישי.
- מצב ביניים של אינדוקס מזוהה כשגיאת הזמנה ייעודית ואינו משאיר את מסך הכניסה בלולאת טעינה כללית.

## אימות

- נוספה בדיקת רגרסיה לחשבון חדש שאינו משתתף עדיין באירוע ומוודאת שאין ניסיון אינדוקס מוקדם.
- בדיקת שני החשבונות החיה הורחבה לאירוע מבודד ולחשבון חדש, כולל כניסה בקישור ב־WebKit במידות iPhone, שמירת חברות קנונית ואינדוקס האירוע בחשבון האישי.
- נשמרה בדיקה נפרדת שלפיה משתתף קיים עדיין מאונדקס מיד עם מימוש הזמנה פרטית.
