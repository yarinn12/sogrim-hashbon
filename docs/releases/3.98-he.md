# סוגרים חשבון 3.98 (125)

## מה חדש

- בהעלאת תמונת פרופיל נפתח בורר חיתוך עגול שמציג מראש בדיוק את האזור שיופיע באפליקציה.
- בהעלאת תמונת אירוע נפתח בורר חיתוך מלבני ביחס 16:7, זהה ליחס שבו התמונה מוצגת באירוע.
- אפשר להזיז את התמונה, להגדיל אותה, לאפס את הבחירה או לבטל בלי לשנות את התמונה הקיימת.
- תמונות שמצורפות להוצאות נשמרות במלואן כדי לא לחתוך מידע מקבלה או מאסמכתה.
- גרסת ה־PWA הועלתה ל־381 כדי שגם התקנות קיימות ימשכו את מודול החיתוך החדש.

## אימות

- החיתוך נבדק בלחיצה אמיתית בפרופילי Android, iPhone ו־iPad.
- יחס התצוגה, השמירה המקומית והישרדות התמונה לאחר רענון נבדקו אוטומטית.
- 1,364 בדיקות יחידה ואינטגרציה עברו ללא כשל.
