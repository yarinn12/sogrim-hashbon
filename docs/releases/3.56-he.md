# סוגרים חשבון 3.56 (81)

## מה השתנה

- קישורי הזמנה, הפניה והתחברות מאומתים רק מול הדומיין הציבורי הקבוע של האפליקציה.
- שרת הגיבוי נשאר זמין לקריאות API, בלי להופיע בטעות כדומיין קישורים למשתמש.
- בדיקת מוכנות החנות בודקת כל דרישה מול הדומיין המתאים לה.

## אימות לפני הפצה

- בדיקות App Links עבור `/i/`, `/r/` ו-`/auth/callback`.
- בדיקת מוכנות Android לחנות.
- בדיקות יחידה, סנכרון ותרחישי שימוש קיימים.
