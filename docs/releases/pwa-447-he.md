# PWA 447

- מוסיף בדיקת סנכרון חיה דרך ממשק ה־iPhone בין שני חשבונות אמיתיים זמניים.
- מאמת שיצירת פתק משותף במכשיר אחד מגיעה לחשבון השני דרך השרת, ללא רענון ידני.
- מאמת שעריכת פתק ומחיקתו מופיעות אוטומטית במסך הפתקים הפתוח במכשיר השני.
- שומר את בדיקות ההוצאות, ההרשאות, התשלומים, סגירת האירוע וההתאוששות כחלק משער הפריסה המלא.
- מעדכן את מטמון ה־PWA כדי שכל המכשירים יקבלו את גרסת הסנכרון המאומתת.
