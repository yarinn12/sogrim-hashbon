# סוגרים חשבון 3.49 (72)

- העברות שהושלמו לאותו אדם מוצגות בשורה אחת ברורה, בלי לפצל את היסטוריית התשלום.
- סנכרון אירועים משותפים חוזק כדי שכל המשתתפים יקבלו הוצאות ועדכונים חדשים.
- תפריטי הוצאות נסגרים באופן טבעי בלחיצה מחוץ לתפריט.
- הוספת משלם יחיד משלימה שוב את יתרת ההוצאה אוטומטית.
- הגדרות נגישות, עיגול סכומים ואופן ההחזר מוצגות בצורה ברורה ועקבית יותר.
