# גרסה 469 — ניסיון חוזר למחיקת פתק

- תוקן כפתור מחיקה שלא הגיב אחרי סנכרון חלקי: ניתן לאשר שוב את המחיקה גם כשהפתק כבר הוסר מהעותק המקומי.
- הניסיון החוזר שולח את סימון המחיקה המקורי לאותו אירוע, בלי לחדש את זמן המחיקה או ליצור פעולה כפולה.
- ניסיון חוזר מותר רק לאותו חשבון ולאותו פתק, עם הרשאת עריכה תקפה. מחיקה שהתקבלה ממכשיר אחר לבדה אינה יוצרת הרשאה לשליחה חוזרת.
- בזמן שהמחיקה ממתינה לאישור, תוכן הפתק נשאר לקריאה בלבד והכפתור מציע ניסיון נוסף למחיקה, במקום עריכה של פתק שכבר הוסר מקומית.
- כשל נוסף שומר את הכוונה הקודמת ומציג את סיבת הכשל, בלי לטעון בטעות שלא בוצע שום שינוי.
- נוספו שבע בדיקות התנהגות ותרחיש דפדפן של מחיקה חלקית והתאוששות.
- אימות: 2,143 בדיקות קוד ו־25 תרחישי דפדפן עברו. הבדיקות נעשו עם נתונים מדומים ובהדמיות מכשירים.
- אין שינוי במסד הנתונים, בהרשאות השרת, בשירותים בתשלום או בבינארי של האפליקציה.
