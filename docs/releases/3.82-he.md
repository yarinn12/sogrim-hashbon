# סוגרים חשבון 3.82 (109)

## מה תוקן

- יצירת קישור קבוע, QR ושיתוף ב־WhatsApp מזהים session שפג בזמן סנכרון האירוע.
- האפליקציה מרעננת את ההתחברות פעם אחת, מוודאת שזה עדיין אותו חשבון ומנסה שוב אוטומטית.
- אירוע שכבר משותף מאמת את הקישור מול השרת בלי לכתוב מחדש נתונים כספיים שאינם קשורים לפעולת השיתוף.
- אירוע חדש עדיין מתפרסם לפני יצירת הקישור; snapshot חסר מקבל ניסיון תיקון יחיד ומוגבל.
- אימות חוזר מחזיר את אותו קישור קבוע ואינו מבטל או מחליף אותו ללא פעולה מפורשת של המשתמש.
- אם חידוש ההתחברות באמת אינו אפשרי, מוצגת הודעת התחברות מדויקת במקום הודעת חיבור מטעה.
- מעטפת PWA עודכנה לגרסה 354.

## אימות

- מסלול “קוריאה” נבדק ידנית ב־Android 3.82: קישור, העתקה, WhatsApp ו־QR זמינים.
- שתי קריאות רצופות לשרת החזירו אותו טוקן, ללא rotation, ונשאר קישור פתוח פעיל אחד.
- כל 1,330 בדיקות היחידה והאינטגרציה עברו.
