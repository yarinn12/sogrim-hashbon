# סוגרים חשבון 3.64 (90)

## מה השתנה

- סנכרון אירוע בין כמה חשבונות ומכשירים הוקשח כדי למנוע אובדן עדכונים או חזרה של משתתף שהוסר.
- קישורי הצטרפות פרטיים ופתוחים מבודדים כעת לכל אירוע וקבוצה ומוגנים מפני שימוש חוזר לא מורשה.
- בקשות חברות תומכות בלחיצה חוזרת ובבקשה הדדית בלי להיחסם בטעות, לצד הגנה מפני ספאם.
- התראות אירוע נשלחות רק למשתתפים פעילים ומספר מכשירי ההתראה לכל חשבון מוגבל בצורה בטוחה.
- מסלולי משוב, מחיקת חשבון ופעולות שרת רגישות קיבלו הרשאות והגבלת קצב מחמירות יותר.
- בחירת איש קשר ב-Android מסננת קלט חריג ושומרת על שמות קצרים ותקינים.

## אימות לפני הפצה

- 1,210 בדיקות יחידה ואינטגרציה עברו ללא כשל.
- 96 תרחישי מובייל עברו ב-Android, ב-iPhone, עם טקסט מוגדל וב-200% reflow.
- תרחישי ענן חיים עברו עבור משוב, רשת חברים ושני חשבונות המשתפים אירוע.
- סכימת Supabase נבדקה ב-dry-run, הוחלה בייצור ואומתה מחדש מול מסד הנתונים החי.
