# סוגרים חשבון 3.74 (101)

- שינוי שנתקל בקונפליקט בין מכשירים נשמר מקומית ולא מתבטל.
- הסנכרון מנסה שוב אוטומטית בשלושה מרווחים קצרים ומוגבלים.
- הודעות שמירה מבחינות בין קונפליקט, סשן שפג, חוסר הרשאה ודחיית השרת.
- נוסף לוג טכני בטוח שמכיל רק קודי שגיאה וסטטוסים, ללא נתוני משתמש או פרטי אירוע.
- תמונת פרופיל חדשה מסתנכרנת כעת לקבוצות ולמכשירים האחרים לפי זמן העדכון האחרון, בלי שתמונה ישנה תדרוס אותה.
- אירועים משותפים קיימים מקבלים תיקון חד־פעמי אוטומטי של תמונת הפרופיל בפתיחה הראשונה לאחר העדכון.
- Cache האתר עודכן ל־`settle-friends-live-v335` כדי שהשינוי יגיע ל־PWA ול־iPad.
- בדיקת סנכרון חיה לשני חשבונות עברה, כולל iPhone מדומה, שיתוף, הוצאות מקבילות וסגירת אירוע.
