# סוגרים חשבון 3.50 (73)

- סנכרון משותף חזק יותר בין כמה משתתפים שעורכים אירוע במקביל.
- מניעת חזרה לאירוע דרך קישור ישן לאחר הסרת משתתף.
- שיפור שמירת הגדרות האירוע ושחזור בטוח במקרה של כשל רשת.
- חיזוק פרטיות החברויות, ההזמנות וההתראות בין חשבונות.
- שיפור תאימות לטקסט מוגדל, ניווט Android ויעדי לחיצה נגישים.
- תיקוני יציבות וליטושי ביצועים במסכי אירוע, סיכום ומשתתפים.
