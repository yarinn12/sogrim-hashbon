# PWA 450

## מה תוקן

- התראת push שמגיעה בזמן הפעלה קרה נשמרת בתור קצר עד שמודול האפליקציה מוכן לקבל אותה.
- סנכרון שמופעל מהתראה ממתין לסיום טעינת החשבון והמצב הראשוני לפני קריאת האירוע המשותף.
- לאחר שהמאזין פעיל, התראות חדשות עוברות ישירות ולא מוכפלות דרך תור האתחול.

## אימות

- נוספה בדיקה התנהגותית שמדמה התראה שמגיעה לפני עליית האפליקציה ומוודאת שהיא נמסרת פעם אחת בלבד.
- נוספו בדיקות רגרסיה לסדר: מוכנות חשבון, טעינת מצב, סנכרון אירוע ורק לאחר מכן רענון תיבת ההתראות.
