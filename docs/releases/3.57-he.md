# סוגרים חשבון 3.57 (82)

## מה השתנה

- שינוי עיגול סכומים ושיטת ההחזר בונה מחדש רק את ההעברות הפתוחות, בלי לצבור שורות ישנות.
- המערכת נמנעת מהעברות הפוכות מיותרות לאחר שתשלום כבר סומן כהושלם.
- שינוי עיגול נשמר בענן לפני אישור למשתמש, וחוזר למצב הקודם אם השמירה נכשלת.

## אימות לפני הפצה

- בדיקות מעבר חוזר בין עיגול מדויק לעיגול נוח.
- בדיקות היסטוריית תשלומים והעברות הפוכות הכרחיות ולא הכרחיות.
- בדיקות יחידה מלאות, עומס וסנכרון מקבילי.
