# סוגרים חשבון 3.55 (78)

- שמירת אירוע משותף מתבצעת לפני שמירת העותק האישי, כדי למנוע מצב שבו חברים רואים נתונים שונים.
- שינוי הוצאות, משתתפים והגדרות נחסם במצב לא מקוון עד לחזרת חיבור תקין.
- שמירה שנכשלה משחזרת את הגרסה האחרונה שאושרה בענן במקום להציג שינוי שלא הגיע לקבוצה.
- שיפורי יציבות בסנכרון בין כמה משתמשים ומכשירים.
