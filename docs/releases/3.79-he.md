# סוגרים חשבון 3.79 (106)

## מה השתנה

- משתמש שממתין לאימות מייל יכול לשלוח קישור אימות חדש ישירות ממסך הכניסה.
- מסלול השחזור נבדק מול שירות האימות החי, כולל קישור חזרה מאובטח ל־Web, ל־PWA ול־Android.
- בדיקת שלמות חיה מאמתת שאין כפילות באימיילים, בשמות משתמש, בחברויות, במרחבי חשבון או בזהות מחוברת בתוך אירוע.
- הודעה צפה אינה חוסמת יותר שורות או כפתורים שמתחתיה, וכפתור הסגירה שלה נשאר יעד מגע נגיש בגודל 44px.
- מעטפת ה־PWA ‏350 מכריחה iPhone ו־iPad לקבל את הקוד העדכני לאחר התקנה או פתיחה מחדש.

## בדיקות

- 1,308 בדיקות יחידה ואינטגרציה.
- מסלולי אימות, שכחתי סיסמה ושליחה חוזרת ב־Android, iPhone ו־iPad.
- בדיקות חיות לשני חשבונות, קישורי הזמנה, חברים, התראות, שמירה בענן ומחיקה בין מכשירים.
- בדיקת שלמות נתוני החשבונות בייצור ובדיקת זמינות של Supabase Auth ו־Data API.
