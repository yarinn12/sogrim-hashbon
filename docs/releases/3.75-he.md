# סוגרים חשבון 3.75 (102)

- תמונת הפרופיל מקבלת גרסת סנכרון עצמאית ונשארת אחידה בין מכשירים, קבוצות ואירועים.
- התקנה חדשה שאין בה מידע על תמונה אינה יכולה עוד למחוק תמונה שנבחרה במכשיר אחר.
- מחיקה מפורשת של תמונה עדיין מסתנכרנת בצורה תקינה לכל המכשירים.
- השרת חוסם ניסיונות דריסה שמגיעים מגרסאות ישנות ללא גרסת תמונה.
- עדכון זהה של שם המשתמש אינו משנה עוד את חותמת הפרופיל ואינו מפעיל רענון תמונה שגוי.
- מעטפת מסך הבית עודכנה ל־`settle-friends-live-v344` עבור iPhone ו־iPad.
- בדיקת Android חיה עברה בחירת תמונה, ניסיון דריסה מגרסה ישנה וחמישה מחזורי רקע וחזרה.
