# PWA 449

- מחזק את מחסום הסנכרון של התראות צירוף: המשתתף נחשב מוצג רק לאחר שגם רשומת הפרופיל שלו זמינה למסך.
- שומר את מטען ההתראה הנייטיבי בזמן הניווט, כך שלחיצה על ההתראה ממתינה לפעילות המדויקת ולא רק לעצם קיום האירוע.
- משאיר טעינה נקייה כמנגנון התאוששות אם המצב הקנוני עדיין אינו זמין לאחר ניסיונות הרענון הקצרים.
