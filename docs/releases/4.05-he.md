# סוגרים חשבון 4.05 (133)

## מה תוקן

- אחרי סגירת אירוע כל כפתורי הניווט חוזרים מיד למצב לחיץ.
- בית, פרופיל ושאר סרגל הניווט נבדקו בלחיצה בפועל לאחר אישור הסגירה.
- סנכרון אירועים, מחיקת הוצאות, קישורי הצטרפות והרשאות עריכה חוזקו מול הענן.
- מסך הבית מקבל סמל אפליקציה חדש, בלי לשנות את המיתוג הפנימי.

## אימות

- תרחיש סגירת אירוע עבר ב־Android, iPhone, iPad, טקסט מוגדל ו־reflow.
- כל 1,416 בדיקות הקוד עברו ללא כשל.
- נבדק שלא נשארת שכבת חלון או חסימת `inert` לאחר הסגירה.

## יעד הפצה

- Web/PWA: גרסה 396 לייצור.
- Android: גרסה 4.05, קוד Build 133, למסלול הבדיקות הפנימיות.
- iOS/iPadOS: גרסה 4.05, Build 128, ל-TestFlight.
