# סוגרים חשבון 3.62 (87)

## מה השתנה

- כל בקשות ה־API, קישורי ההזמנה והתראות הניווט משתמשים רק ב־Vercel החדש.
- הוסר נתיב Render הישן מקוד ה־runtime ומרשימת הכתובות המורשות.
- אפליקציית Android ממשיכה לעבוד עם נתוני ה־Supabase המובנים גם בזמן תקלה זמנית בשרת התצורה, בלי לעבור לשרת ישן.
- בדיקת המוכנות לחנות מאמתת מעכשיו את אותה כתובת ייצור שבה משתמשת האפליקציה.
- מסך הפתיחה נסגר מיד כשהכניסה והמסך הראשון מוכנים, בלי להמתין לסיום הסרטון.
- מדיניות עדכון תקינה שמוטמעת בחבילה נבדקת מיד; הרענון מ־Vercel ממשיך ברקע ואינו מעכב את הפתיחה.

## אימות לפני הפצה

- 1,193 בדיקות יחידה עברו ללא כשל.
- תרחיש חי של שני חשבונות עבר הזמנה, סנכרון הוצאות, שינוי מקביל, התחשבנות, סגירה, הסרת משתמש וחסימת קישור ישן.
- רשת חברים, זיכרון אישי, משוב ותיבת התראות נבדקו מול Supabase הפעיל ונוקו בסיום.
- חבילת Android נבנית מהמקור שנפרס ב־`sogrim-hesbon-app.vercel.app` בלבד.
