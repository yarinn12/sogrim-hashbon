# סוגרים חשבון 3.34 (57)

## מה השתנה

- כפתור "הוסף הוצאה" אינו נשאר מאחורי מסך המשתתפים או חלון פנימי אחר באירוע.
- התיקון מבוצע ברינדור עצמו ואינו תלוי בתמיכת ה-WebView בכלל CSS מסוג `:has()`.
- מטמון האפליקציה עודכן כדי שהגרסה החדשה תחליף קבצים ישנים באופן עקבי.

## אימות

- בדיקות הלוגיקה והבטיחות עברו בהצלחה.
- זרימת מסך האירוע עברה ב-Android, ב-iPhone, בטקסט מוגדל וב-reflow של 200%.
