# גרסה 468 — ניסיון חוזר בטוח לשמירת פתקים

- פתק שלא קיבל אישור בסנכרון חלקי נשאר אותה פעולה: ניסיון חוזר בפתק חדש משתמש באותו מזהה ואינו יוצר עותק נוסף.
- ניסיון חוזר בפתק קיים שולח שוב את השמירה גם אם הטקסט לא השתנה. עותק מקומי ממתין אינו נחשב לאישור מהשרת.
- אפשר לעדכן את הטיוטה שנשארה אחרי כשל חלקי בלי שהעריכה הקודמת של אותו משתמש תזוהה כשינוי ממכשיר אחר.
- השדות שעדיין ממתינים לאישור נבדקים גם בקבלה הסופית. שינוי מתחרה או מחיקה ממכשיר אחר אינם נדרסים בשקט.
- קבלת מזהה עבור טיוטה חדשה אינה מוסיפה מסך להיסטוריית הדפדפן; שמירה מוצלחת אינה פותחת שוב את החלון הישן.
- נוספו שמונה בדיקות התנהגות ותרחישי דפדפן של סנכרון חלקי וניסיון חוזר ליצירה ולעריכה.
- אימות: 2,136 בדיקות קוד ו־20 תרחישי דפדפן עברו. בדיקות המכשירים הן בהדמיה ועם שרת מדומה.
- אין שינוי במסד הנתונים, בהרשאות, בתוכניות בתשלום או בבינארי של האפליקציה.
