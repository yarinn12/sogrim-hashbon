# גרסה 4.50 (179), PWA 499

חדש: הצמדת אירועים לראש הרשימה בעיצוב המוכר מהפתקים. ההצמדה אישית ונשמרת במכשיר, עם תמיכה בביטול הצמדה, ארכיון וסינון. נוספו בדיקות לנעיצות ברצף, לרענון, לשתי לשוניות ולהתאוששות מכשל בשמירה.

דרך תפריט האפשרויות או לחיצה ארוכה על האירוע אפשר להצמיד אותו לראש הרשימה. לחיצה נוספת מבטלת את ההצמדה ומחזירה את סדר האירועים הרגיל. הסיכה, הכפתור וכותרת ״מוצמד״ משתמשים באותם רכיבי עיצוב של הפתקים. ההצמדה אינה משותפת ואינה מסתנכרנת בין מכשירים.

הבדיקות כוללות שמירת העדפות נפרדות לכל משתתף, נעיצה וביטול נעיצה ברצף, רענון, ארכיון וסינון, שתי לשוניות, עדכון אירוע נכנס ומחיקת אירוע, וכן ניסיון חוזר אחרי כשל באחסון. השוואת עיצוב אוטומטית בודקת את ערכי ה־CSS ואת סמל ה־SVG מול הפתקים. בדיקות iPhone נעשות ב־WebKit מדומה; לא בוצעה בדיקה באייפון פיזי.
