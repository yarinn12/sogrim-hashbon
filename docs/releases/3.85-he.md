# סוגרים חשבון 3.85 (112)

## מה תוקן

- קישורי איפוס סיסמה מופנים תמיד לאתר החדש ולא לכתובת הפריסה הישנה.
- איפוס הסיסמה נבדק מקצה לקצה: יצירת קישור, אימות הטוקן, החלפת סיסמה, דחיית הסיסמה הישנה וכניסה עם החדשה.
- הרשמה באימייל דורשת כתובת תקינה ומנורמלת, וכתובות חלקיות או לא תקינות נחסמות לפני שליחת בקשה.
- אימות כתובת אימייל נדרש לפני כניסה לחשבון חדש, והאפליקציה מסבירה זאת כבר בטופס ההרשמה.
- בדיקת Production עוקבת מעכשיו גם אחר הפעלת ספק האימייל ואחר הדרישה לאימות כתובת, כדי למנוע כיבוי שקט של ההגנה.
- מעטפת PWA עודכנה לגרסה 361 כדי שהאתר והתקנות מסך הבית ימשכו את קוד האימות החדש.
- פרויקטי Android ו־iOS עודכנו יחד לגרסה 3.85 ול־build 112.

## אימות

- כל 1,336 בדיקות היחידה, האינטגרציה והאבטחה עברו לפני אריזת הגרסה.
- 20 תרחישי אימות ב־Playwright עברו ב־Android, iPhone, iPad, טקסט מוגדל ו־reflow; ארבע בדיקות מגע שאינן רלוונטיות למקלדת סומנו כ־skip צפוי.
- בדיקת Auth חיה אישרה שהרשמה לא־מאומתת חסומה ושאיפוס סיסמה אמיתי עובד מול Supabase Production.
- משתמשי הבדיקה הזמניים נמחקו אוטומטית בסיום הבדיקה.

## שער השקה פתוח

- לפני פתיחת הרשמה באימייל לציבור יש לחבר SMTP מותאם ודומיין שולח מאומת. עד אז `AUTH_EMAIL_DELIVERY_READY` נשאר כבוי ובדיקת Production המחמירה תיכשל במכוון.
