# גרסה 4.56 (186), PWA 506 — עדכון מוכנות

תוקנו יציאה מקבוצה ושחזור פעולה שנדחתה בלי לאבד שינויים מקבילים, שמירת בקשות התראה בזמן ניתוק וניסיון חוזר אחרי חזרת החיבור, ורענון הוצאות שנחסם בגלל טעינה איטית של חברים או תיבת ההתראות. נשמרו פירוט הסכום לכל משלם והסרת נקודות הסטטוס ליד תמונות הפרופיל. נוסף תיקון קטן לגלישת כיתוב במסך הבית.

המקור כולל גם את תיקוני ההתחברות שהגיעו ל־main. חבילת Android ‏4.56 (186) נבנתה ונחתמה עם מפתח ההעלאה הקיים; בניית Release ו־lint עברו. תיקון מסד העזיבה ותלויותיו הותקנו ואומתו ללא שכתוב תוכן משתמשים. האתר והשרת המעודכנים פעילים.

החבילה עדיין לא הועלתה ל־Google Play. הגישה לכלי הדפדפן של חשבון המפתח חסומה בסביבת העבודה; מספר הבנייה, תעודת ההעלאה והמסלול בחנות טעונים אימות ב־Play Console לפני ההגשה. קבלת התראה והתקנה דרך החנות במכשיר פיזי לא אומתו. תוצאות הבדיקות והחבילה החתומה נשמרו בדוח השחרור המקומי.
