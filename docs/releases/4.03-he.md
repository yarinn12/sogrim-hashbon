# סוגרים חשבון 4.03 (131)

## מה חדש

- מסך בקרת המוצר מציג כעת משתמשים פעילים, יציבות לפי פלטפורמה, כשלים לפי סיבה, רציפות נתונים ומצב משלוחי Push — בלי מידע אישי.
- תקלות זמניות ברשת מופרדות מכשלים סופיים כדי שלא להציג מצב חירום על פעולה שכבר ממתינה לסנכרון.
- חשבונות חדשים מקבלים סביבת ענן תקינה, ושער השחרור עוצר אם מתגלה חשבון פעיל או אירוע נגיש ללא חיבור נתונים תקין.
- שרת ה־API מפיק אבחון מובנה ומצונזר עם מזהה בקשה וזמן תגובה, ללא כתובות מייל, אסימונים או פרמטרים מהקישור.
- שער Android מאמת מיפוי R8 לקריסות Java וחוסם כל ספריית Native חדשה שאין עבורה סמלי קריסה; שלוש ספריות צד שלישי קיימות מתועדות במפורש כ־pre-stripped.
- גרסת ה־PWA הועלתה ל־391 כדי שהאתר והתקנות מסך הבית יקבלו את העדכון באופן אוטומטי.

## אימות

- בדיקות אופליין, חזרה לרשת, התנגשויות ושמירה משני מכשירים עברו ללא אובדן מידע.
- בדיקת הרציפות החיה עברה ללא חשבונות חסרים, אירועים נגישים ללא חברות או משלוחי Push תקועים.
- Android עובר Build, ‏Lint, אימות חתימה, התאמה למקור ואימות כיסוי אבחון הקריסות.

## יעד הפצה

- Web/PWA: גרסה 391 לייצור.
- Android: גרסה 4.03, קוד Build ‏131, למסלול הבדיקות הפנימיות.
- Apple: ללא שינוי בסבב זה, עד לקבלת תשובה מחשבון המפתחים.
