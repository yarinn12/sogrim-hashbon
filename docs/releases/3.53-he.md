# סוגרים חשבון 3.53 (76)

- הכנת מנגנון עדכון חובה בטוח לגרסאות Android עתידיות.
- מסך עדכון מלא ונגיש שמוביל ישירות ל-Google Play.
- בדיקת מדיניות הגרסה מחדש עם החזרה לאפליקציה ועם חידוש החיבור.
- שמירת כל האירועים והמידע האישי בזמן עדכון האפליקציה.
- שיפורי יציבות ובדיקות קצה במסכי האתחול והכניסה.
