# סוגרים חשבון 3.54 (77)

- הפרדה מלאה יותר בין חשבונות שמתחברים מאותו מכשיר.
- הרשמה חדשה אינה מקבלת שם או דוגמה מהמשתמש הקודם.
- מחיקת אירוע משותף מסתנכרנת כעת לכל המכשירים שהשתתפו בו.
- חיזוק סנכרון הוצאות, תשלומים וסטטוס אירוע בין משתמשים.
- שיפורי יציבות בטעינה, בעדכון האפליקציה ובתצוגת מובייל.
